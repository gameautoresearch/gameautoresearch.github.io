# Ruin

Explorable ruin. An idle unit can examine it; reward selection is deterministic for the pinned public game state/seed but the policy receives no seed. The ruin disappears.

| Property | Value |
|---|---|
| ID | 2 |
| Table cost | no ordinary price |
| Base population | 0 |
| Fixed score | 0 |
| Stars per work level | 0 |
| Terrain | special/preplaced |
| Resource | none |
| Adjacent requirements | none |
| One per ruling city | False |
| One per tribe table flag | False |
| Tech unlocks | special/preplaced/task |

The table is necessary but not sufficient for legality: economic territory, tile ruling city, ownership, occupancy, free improvement slot, resources, adjacency, unique/task flags, bridges and the current mask all apply. See [buildings and connections](../rules/buildings-and-connections.md).
