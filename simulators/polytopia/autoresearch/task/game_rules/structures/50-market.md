# Market

Limited to one per ruling city. Income level sums adjacent same-owner Windmill/Sawmill/Forge levels, with each neighbor at least1, capped at8. Each level supplies1 star. Market work is paid separately even if its city is besieged.

| Terrain | field |

| Adjacent requirements | Windmill, Sawmill, Forge |
| One per ruling city | True |
| One per tribe table flag | False |
| Tech unlocks | Trade |

The table is necessary but not sufficient for legality: economic territory, tile ruling city, ownership, occupancy, free improvement slot, resources, adjacency, unique/task flags, bridges and the current mask all apply. See [buildings and connections](../rules/buildings-and-connections.md).
