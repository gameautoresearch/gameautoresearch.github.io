# Catapult

Range-three siege unit. No Dash and Stiff prevents retaliation. Movement and a normal attack cannot be combined in the same turn.

| Property | Value |
|---|---|
| ID | 8 |
| Base HP | 10.0 |
| Attack | 4.0 |
| Defense | 0.0 |
| Movement | 1 |
| Range (Chebyshev tiles) | 3 |
| Nominal star cost | 8 |
| Skills | Stiff |
| Availability | City recruit with Mathematics |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
