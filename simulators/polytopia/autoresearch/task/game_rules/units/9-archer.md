# Archer

Range-two land unit with Dash and Fortify. Range does not grant a direct target hidden by fog; retaliation depends on the defender’s range and exploration of the attacker tile.

| Property | Value |
|---|---|
| ID | 9 |
| Base HP | 10.0 |
| Attack | 2.0 |
| Defense | 1.0 |
| Movement | 1 |
| Range (Chebyshev tiles) | 2 |
| Nominal star cost | 3 |
| Skills | Dash, Fortify |
| Availability | City recruit with Archery |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
