# Scoutship

Raft upgrade unlocked by Sailing; costs five stars. Carries its passenger and has range two, Dash and Scout. Actual max HP uses passenger HP, not blindly the ten-HP table row.

| Property | Value |
|---|---|
| ID | 42 |
| Base HP | 10.0 |
| Attack | 2.0 |
| Defense | 1.0 |
| Movement | 3 |
| Range (Chebyshev tiles) | 2 |
| Nominal star cost | 5 |
| Skills | Carry, Dash, Float, Scout, Static |
| Availability | City recruit with Sailing |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
