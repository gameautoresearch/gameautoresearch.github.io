# Knight

Fast chain-attacking unit. A kill can preserve another attack through Persist, but the engine checks that another target exists from the resulting location. Not an unconditional unlimited action flag.

| Property | Value |
|---|---|
| ID | 4 |
| Base HP | 10.0 |
| Attack | 3.5 |
| Defense | 1.0 |
| Movement | 3 |
| Range (Chebyshev tiles) | 1 |
| Nominal star cost | 8 |
| Skills | Dash, Fortify, Persist |
| Availability | City recruit with Chivalry |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable. See [skills](../rules/unit-skills.md), [combat](../rules/combat.md), [naval play](../rules/naval.md) and [recruitment](../rules/cities-and-economy.md).
