# Giant

Obtained by a city SuperUnit reward, not by paying its nominal table cost. Static prevents promotion. Embarking converts it to Juggernaut; its land form is implicit rather than a separate ordinary passenger field.

| Property | Value |
|---|---|
| ID | 12 |
| Base HP | 40.0 |
| Attack | 5.0 |
| Defense | 4.0 |
| Movement | 1 |
| Range (Chebyshev tiles) | 1 |
| Nominal star cost | 10 |
| Skills | Static |
| Availability | City reward |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
