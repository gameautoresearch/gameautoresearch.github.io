# Defender

Low attack, high defense garrison. No Dash: moving consumes its ability to attack that turn. Fortify enables own-city defense.

| Property | Value |
|---|---|
| ID | 5 |
| Base HP | 15.0 |
| Attack | 1.0 |
| Defense | 3.0 |
| Movement | 1 |
| Range (Chebyshev tiles) | 1 |
| Nominal star cost | 3 |
| Skills | Fortify |
| Availability | City recruit with Strategy |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
