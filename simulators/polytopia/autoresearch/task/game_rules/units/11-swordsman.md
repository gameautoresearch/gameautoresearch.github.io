# Swordsman

Strong general-purpose melee recruit. Dash permits attacking after movement. It lacks Fortify in this pinned table, so do not assume a city defense multiplier merely because it is a land melee unit.

| Property | Value |
|---|---|
| ID | 11 |
| Base HP | 15.0 |
| Attack | 3.0 |
| Defense | 3.0 |
| Movement | 1 |
| Range (Chebyshev tiles) | 1 |
| Nominal star cost | 5 |
| Skills | Dash |
| Availability | City recruit with Smithery |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
