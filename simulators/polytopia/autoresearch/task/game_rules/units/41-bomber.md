# Bomber

Raft upgrade unlocked by Navigation; costs fifteen stars. Range-three Splash attacks. Stiff prevents retaliation; no Dash. Splash uses the pinned half-damage/event ordering rather than an independent full-strength attack on every neighbor.

| Property | Value |
|---|---|
| ID | 41 |
| Base HP | 10.0 |
| Attack | 3.0 |
| Defense | 2.0 |
| Movement | 2 |
| Range (Chebyshev tiles) | 3 |
| Nominal star cost | 15 |
| Skills | Carry, Float, Splash, Static, Stiff |
| Availability | City recruit with Navigation |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
