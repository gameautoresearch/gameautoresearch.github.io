# Rider

Fast land unit. Dash permits attacking after a normal move; Escape leaves its movement available after attacking. Its destination is still constrained by terrain and zone of control.

| Property | Value |
|---|---|
| ID | 3 |
| Base HP | 10.0 |
| Attack | 2.0 |
| Defense | 1.0 |
| Movement | 2 |
| Range (Chebyshev tiles) | 1 |
| Nominal star cost | 3 |
| Skills | Dash, Escape, Fortify |
| Availability | City recruit with Riding |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
