# Rammership

Raft upgrade unlocked by Ramming; costs five stars. Range-one naval melee, Dash and strong defense. A water ruin can instead create a veteran Rammership with an implicit Warrior passenger.

| Property | Value |
|---|---|
| ID | 44 |
| Base HP | 10.0 |
| Attack | 3.0 |
| Defense | 3.0 |
| Movement | 3 |
| Range (Chebyshev tiles) | 1 |
| Nominal star cost | 5 |
| Skills | Carry, Dash, Float, Static |
| Availability | City recruit with Ramming |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
