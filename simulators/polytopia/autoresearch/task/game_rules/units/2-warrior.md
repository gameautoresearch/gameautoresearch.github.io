# Warrior

The starting Bardur unit and a two-star recruit. Dash permits attacking after a normal move. Fortify permits the own-city defense bonus.

| Property | Value |
|---|---|
| ID | 2 |
| Base HP | 10.0 |
| Attack | 2.0 |
| Defense | 2.0 |
| Movement | 1 |
| Range (Chebyshev tiles) | 1 |
| Nominal star cost | 2 |
| Skills | Dash, Fortify |
| Availability | City recruit with Basic |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
