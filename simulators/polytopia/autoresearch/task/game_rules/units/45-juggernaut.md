# Juggernaut

Embarked Giant. Stomp damages adjacent enemies upon eligible arrival/embarkation; forced push explicitly suppresses arrival Stomp. Static and Stiff apply. Disembarking restores Giant.

| Property | Value |
|---|---|
| ID | 45 |
| Base HP | 40.0 |
| Attack | 4.0 |
| Defense | 4.0 |
| Movement | 2 |
| Range (Chebyshev tiles) | 1 |
| Nominal star cost | 10 |
| Skills | Carry, Float, Static, Stiff, Stomp |
| Availability | Embarkation, infiltration or upgrade transformation; not ordinary direct recruitment |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
