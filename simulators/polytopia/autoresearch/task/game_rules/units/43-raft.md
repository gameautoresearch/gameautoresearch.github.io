# Raft

The initial transport formed when an ordinary land unit enters a usable port. It has no positive attack, carries the passenger’s health/veterancy and can be upgraded only while in friendly territory. It is not recruited as a free combat unit directly.

| Property | Value |
|---|---|
| ID | 43 |
| Base HP | 10.0 |
| Attack | 0.0 |
| Defense | 1.0 |
| Movement | 2 |
| Range (Chebyshev tiles) | 2 |
| Nominal star cost | 0 |
| Skills | Carry, Float, Static, Stiff |
| Availability | Embarkation, infiltration or upgrade transformation; not ordinary direct recruitment |

Base table HP is overridden by a passenger’s max HP for ordinary transport boats; veteran passengers add5 HP. Nominal costs are also used for score and disband refunds, not a promise that this form is directly purchasable.
