# Pokémon: offline Gen 9 Random Battle wiki

This is the rulebook for the pinned **singles `gen9randombattle`** mode at Showdown
`567c1cedddeaa2f35576005d3bfd526cf4f8a13e`. It contains the entire published singles
set pool and its moves, abilities, item candidates, relevant formes and persistent
effects. No internet, external wiki or private opponent data is required to read it.

## Complete content indexes

- [Species and formes](species/README.md): every role template, level, base stat,
  ability, Tera choice and candidate move for all 509 direct records; generated
  cosmetics and relevant battle transformations are identified separately.
- [Moves](moves/README.md): every 348 directly generated moves plus Struggle, with
  power, type, category, accuracy, PP, priority, targets, long effects and exceptions.
- [Abilities](abilities/README.md): initial set choices and induced/forme abilities,
  with full long effects and effect conditions.
- [Items](items/README.md): conservative singles-generator candidates and required
  form items, with effects, consumption/transfer behavior and effect conditions.
- [Conditions](conditions/README.md): persistent effects from those moves,
  abilities/items plus selected relevant base statuses and weather conditions.
- [Type chart](battle/type-chart.md): the complete ordinary attacking/defending matrix.

The readable [scope and limitations](scope-and-limitations.md) describes catalog boundaries and uncertainty. Additional values appear in Markdown tables, with no implementation appendices.

The old [mechanics overview](mechanics.md) and [interface entry](interface.md) remain
short navigation summaries; they no longer define a fixed wiki folder template.
