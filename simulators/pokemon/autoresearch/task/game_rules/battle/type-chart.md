# Type chart

[Wiki home](../README.md) · [Tera and formes](tera-and-formes.md)

Rows are attacking move types; columns are the defending single type. Multiply the two
column factors for an ordinary dual type. Immunity is zero. This table excludes
ability/item/grounding overrides and special moves such as Freeze-Dry or Flying Press;
those pages specify exceptions. Stellar is a Tera mechanic rather than an ordinary
defensive type and is described separately.
