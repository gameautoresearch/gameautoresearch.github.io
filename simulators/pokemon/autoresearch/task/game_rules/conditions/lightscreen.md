# Light Screen condition

[Condition index](README.md) · [Wiki home](../README.md)

## Effect and lifetime

For 5 turns, the user and its party members take 0.5× damage from special attacks, or 0.66× damage if in a Double Battle. Damage is not reduced further with Aurora Veil. Critical hits ignore this effect. It is removed from the user's side if the user or an ally is successfully hit by Brick Break, Psychic Fangs, or Defog. Lasts for 8 turns if the user is holding Light Clay. Fails if the effect is already active on the user's side.

This is the persistent condition created by [Light Screen](../moves/lightscreen.md), rather than a separately selectable move.
