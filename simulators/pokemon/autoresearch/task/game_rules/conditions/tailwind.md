# Tailwind condition

[Condition index](README.md) · [Wiki home](../README.md)

## Effect and lifetime

For 4 turns, the user and its party members have their Speed doubled. Fails if this move is already in effect for the user's side.

This is the persistent condition created by [Tailwind](../moves/tailwind.md), rather than a separately selectable move.

## Duration and timing details

| Rule detail | Value |
|---|---|
| Duration | 4 |
| Side residual resolution order | 26 |
| Side residual sequence within stage | 5 |

Durations are measured in battle turns. Switching, fainting or the stated effect-specific conditions may end an effect before its maximum duration.
