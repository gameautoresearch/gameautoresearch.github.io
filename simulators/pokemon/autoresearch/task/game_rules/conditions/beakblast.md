# Beak Blast condition

[Condition index](README.md) · [Wiki home](../README.md)

## Effect and lifetime

If the user is hit by a contact move this turn before it can execute this move, the attacker is burned.

This is the persistent condition created by [Beak Blast](../moves/beakblast.md), rather than a separately selectable move.

## Duration and timing details

| Rule detail | Value |

| Duration | 1 |
