# Focus Punch condition

[Condition index](README.md) · [Wiki home](../README.md)

## Effect and lifetime

The user loses its focus and does nothing if it is hit by a damaging attack this turn before it can execute the move.

This is the persistent condition created by [Focus Punch](../moves/focuspunch.md), rather than a separately selectable move.
