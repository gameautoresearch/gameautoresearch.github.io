# No Retreat condition

[Condition index](README.md) · [Wiki home](../README.md)

## Effect and lifetime

Raises the user's Attack, Defense, Special Attack, Special Defense, and Speed by 1 stage, but it becomes prevented from switching out. The user can still switch out if it uses Baton Pass, Flip Turn, Parting Shot, Teleport, U-turn, or Volt Switch. Fails if the user has already been prevented from switching by this effect.

This is the persistent condition created by [No Retreat](../moves/noretreat.md), rather than a separately selectable move.

## Duration and timing details

Durations are measured in battle turns. Switching, fainting or the stated effect-specific conditions may end an effect before its maximum duration.
