# par condition

[Condition index](README.md) · [Wiki home](../README.md)

## Effect and lifetime

Paralysis: effective Speed is halved after other Speed modifiers, except Quick Feet; each attempted action has a 1/4 full-paralysis chance. Electric types normally cannot be paralyzed.
