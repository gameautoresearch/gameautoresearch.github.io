# frz condition

[Condition index](README.md) · [Wiki home](../README.md)

## Effect and lifetime

Freeze: normally prevents moving; each action has a 1/5 thaw chance. A defrost-flag move can thaw the user; damaging Fire hits and explicit thawsTarget effects thaw the target as specified. Ice types normally cannot be frozen.
