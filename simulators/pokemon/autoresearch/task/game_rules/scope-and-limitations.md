## Limits

- No independent exhaustive prose audit of every combination of interacting effects or formal transitive battle-effect reachability proof.
- Item catalog is a conservative static candidate superset, not proof each branch can occur with a current initial template.
- Exact probabilities of every possible four-move/ability/item combination are not tabulated; conditional generator remains authoritative.
- The public 700-value view omits several true game details; wiki knowledge must not be confused with hidden live-state access.

The written rules apply to the pinned mode identified above. Catalog membership does not by itself establish that every combination of effects has been independently tested.
