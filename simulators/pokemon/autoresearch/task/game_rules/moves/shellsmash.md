# Shell Smash

[Move index](README.md) · [Wiki home](../README.md)

**Mode status:** Present in at least one pinned singles set movepool.

## Effect

Lowers the user's Defense and Special Defense by 1 stage. Raises the user's Attack, Special Attack, and Speed by 2 stages.
