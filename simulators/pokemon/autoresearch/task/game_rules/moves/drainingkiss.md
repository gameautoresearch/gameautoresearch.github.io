# Draining Kiss

[Move index](README.md) · [Wiki home](../README.md)

**Mode status:** Present in at least one pinned singles set movepool.

## Effect

The user recovers 3/4 the HP lost by the target, rounded half up. If Big Root is held by the user, the HP recovered is 1.3× normal, rounded half down.
