# Chlorophyll

[Ability index](README.md) · [Wiki home](../README.md)

## Effect

If Sun is active, this Pokemon's Speed is doubled. This effect is prevented if this Pokemon is holding a Utility Umbrella.

**Scope:** Selectable in at least one initial singles Random Battle role template.
