# Speed Boost

[Ability index](README.md) · [Wiki home](../README.md)

## Effect

This Pokemon's Speed is raised by 1 stage at the end of each full turn it has been on the field.

**Scope:** Selectable in at least one initial singles Random Battle role template.

## Additional rule details

| Rule detail | Value |
|---|---|
| Residual resolution order | 28 |
| Residual sequence within stage | 2 |
