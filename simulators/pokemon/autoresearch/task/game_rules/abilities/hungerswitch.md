# Hunger Switch

[Ability index](README.md) · [Wiki home](../README.md)

## Effect

If this Pokemon is a Morpeko, it changes formes between its Full Belly Mode and Hangry Mode at the end of each turn.

**Scope:** Selectable in at least one initial singles Random Battle role template.
