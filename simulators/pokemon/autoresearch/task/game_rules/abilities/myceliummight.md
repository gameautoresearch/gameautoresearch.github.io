# Mycelium Might

[Ability index](README.md) · [Wiki home](../README.md)

## Effect

This Pokemon's Status moves ignore certain Abilities of other Pokemon, and go last among Pokemon using the same or greater priority moves.

**Scope:** Selectable in at least one initial singles Random Battle role template.
