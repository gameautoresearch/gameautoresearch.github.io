# Leaf Guard

[Ability index](README.md) · [Wiki home](../README.md)

## Effect

If Sun is active, this Pokemon cannot become affected by a non-volatile status condition or Yawn, and Rest will fail for it. This effect is prevented if this Pokemon is holding a Utility Umbrella.

**Scope:** Selectable in at least one initial singles Random Battle role template.

## Additional rule details

| Rule detail | Value |
|---|---|
| Can be bypassed by ability-ignoring effects | Yes |
