# Cursed Body

[Ability index](README.md) · [Wiki home](../README.md)

## Effect

If this Pokemon is hit by an attack, there is a 30% chance that move gets disabled unless one of the attacker's moves is already disabled.

**Scope:** Selectable in at least one initial singles Random Battle role template.
