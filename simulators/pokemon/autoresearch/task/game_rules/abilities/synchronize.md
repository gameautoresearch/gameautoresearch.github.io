# Synchronize

[Ability index](README.md) · [Wiki home](../README.md)

## Effect

If another Pokemon burns, paralyzes, poisons, or badly poisons this Pokemon, that Pokemon receives the same non-volatile status condition.

**Scope:** Selectable in at least one initial singles Random Battle role template.
