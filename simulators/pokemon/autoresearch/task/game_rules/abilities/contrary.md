# Contrary

[Ability index](README.md) · [Wiki home](../README.md)

## Effect

If this Pokemon has a stat stage raised it is lowered instead, and vice versa.

**Scope:** Selectable in at least one initial singles Random Battle role template.

## Additional rule details

| Rule detail | Value |
|---|---|
| Can be bypassed by ability-ignoring effects | Yes |

## Initial set-pool holders

[Serperior](../species/serperior.md), [Malamar](../species/malamar.md), [Lurantis](../species/lurantis.md), [Enamorus](../species/enamorus.md)
