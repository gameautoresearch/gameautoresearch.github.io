# Clash fixed8 — offline game wiki

This is the complete **content catalog for the relevant benchmark mode**, plus detailed rules and exact source provenance. It covers the pinned plain eight-card level-11 mirror task; it is not an encyclopedia of every live Clash Royale card. Start with the mode, then use the entity catalog as a reference while researching. All documents are local; no website or internet access is required to read the wiki.
